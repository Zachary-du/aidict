# 📖 MacDict 词典

原生轻量、极速常驻的 macOS 划词/查词与 AI 助理解析工具。

## 🌟 核心特性
- **0 外部第三方依赖**：纯原生 Swift + SwiftUI + AppKit 开发，不依赖 CocoaPods / npm / python 或任何远程第三方库，开箱即编。
- **全平台架构兼容**：原生支持 Apple Silicon（M1/M2/M3/M4）与 Intel (x86_64) Mac。
- **权威词典集成**：支持系统词典、朗文当代、柯林斯高阶等，含原厂真人例句音频与词根智能重定向校验。
- **概念图示与底层通透理解**：伴随式展示单词具象实体插画与“核心画面 + 具象感知 + 灵魂本义与场景贯通”三段式认知解析，零门槛深度意会。
- **AI 智能问答与发音**：支持 OpenAI / Gemini 协议大模型实时词义解析与多轮追问对话，集成神经高拟真发音。
- **离线 OCR 与屏幕取词**：集成 Apple Vision 离线文字识别引擎，支持不可选中文字的取词。

---

## 🛠️ 编译与运行要求

- **操作系统**：macOS 13.0 (Ventura) 或更高版本（Sonoma, Sequoia 等均可）
- **编译工具**：安装 **Xcode** 或仅需安装 **命令行工具 (Command Line Tools)** 即可：
  ```bash
  xcode-select --install
  ```

## 🚀 源码编译与启动（一步完成）

项目内置了全自动化管理脚本 `run.sh`：

### 1. 一键全自动编译、自检并启动
在项目根目录下打开终端，直接运行：
```bash
./run.sh
```
脚本将全自动完成：
1. 本机架构原生 Release 编译；
2. 组装并签名 `MacDict.app`；
3. 执行全部 42 项自动化全量工业级测试；
4. 常驻启动至右上角菜单栏（📖 图标）。

### 2. 常用管理指令
```bash
./run.sh build        # 仅编译并打包生成 MacDict.app
./run.sh start        # 启动应用
./run.sh stop         # 退出应用
./run.sh test         # 运行全部自动化测试套件 (42 项全通)
./run.sh dmg          # 一键生成可分发的 DMG 安装包
./run.sh clean        # 清理 .build 编译缓存
./run.sh config ai    # 交互式配置 AI API Key 与端点
```

## 🔒 首次运行权限说明
由于应用需要屏幕选词与划词，初次启动请在 Mac「系统设置」➔「隐私与安全性」中授予：
1. **辅助功能**（用于全局快捷键与划词检测）
2. **屏幕录制**（仅用于离线 Vision OCR 截图识别不可选中的文本）
